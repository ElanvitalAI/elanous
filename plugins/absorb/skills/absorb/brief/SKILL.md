# Daily briefing

Group only cards returned for the verified member and current KST day. Produce topic groups with source scrap IDs, short summaries, and concrete follow-up todos. A repeated daily run updates the same briefing record; an empty day produces no briefing.

With BYOK, summarize from the supplied cards. Without BYOK, use deterministic card points and do not invoke an LLM. Never include another member's items.
