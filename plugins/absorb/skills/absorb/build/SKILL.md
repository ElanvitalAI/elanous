# Build an accepted suggestion

Use only the owner-verified suggestion and the member app slot returned by the store connector. Make the smallest source change that implements the accepted suggestion and return the generated artifact with evidence linking it to the suggestion and app slot. Do not publish. The graph must send this artifact to isolated simulation and publish only after the simulation produces a passing receipt for the same artifact.
