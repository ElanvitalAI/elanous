# Cloud Burst Basic

Cloud Burst Basic is the free, local-first path: try local capacity, then resume a parked, termination-protected VM with the requested pinned image, then create one VM from that image. If a provider does not confirm termination protection, the adapter attempts an immediate stop and the request fails. Cloud requests carry a TTL stop deadline. Hourly cost and readiness come from the provider adapter quote, never caller-supplied estimates. A report asks the provider adapter for usage scoped to the run receipt, excluding earlier or later uses of a warm VM. The receipt pins the quote used for that run, so a later warm-pool rate cannot rewrite its cost.

The installed `/cloud-burst mock request` and `/cloud-burst mock report` commands use the existing `fake-cloud-vm` simulation device in process-local memory. They do not contact a cloud provider or read credentials. The live command accepts only an opaque, user-owned `--account-ref` profile reference; credential-looking options are rejected, and credentials are never persisted by this plugin. The live provider/account adapter and cloud/domain knowledge-pack ingestion are not included in this mock-first slice. Live requests fail closed until an adapter is connected. Mock receipts do not survive plugin process restarts.

The focused deterministic test exercises the installed command path and the fake clock, including local-first behavior, warm-image reuse, cold creation, termination protection, delayed-preflight TTL start, TTL stop, and a final report that stays fixed after the VM is reused. It proves the mock path only; it does not claim live cloud execution.
