# Plugin wizard

Use `eln plugin market` to inspect configured marketplaces, `eln plugin add` to install a package, and `eln plugin make` to create a local graph plugin. Keep marketplace trust and capability consent visible; report the exact plugin id and version after installation. Claude Code and GitHub CLI authentication use their existing login flows, not API-key prompts.
