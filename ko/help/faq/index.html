FAQ

모든 답은 실물을 눌러 얻었다. 재는 명령을 같이 둔다 — ⛔ 이 문서의 수를 인용하지 말고 그 명령으로 다시 재라. 최종 측정 2026-09-22.

키가 하나도 없으면 elanous 가 도나​

돈다. elanous doctor 가 rc=0 으로 끝나고, 무엇이 잠겼는지 이름을 댄다.

mkdir -p /tmp/empty-home /tmp/empty-cache
env -i PATH="$PATH" HOME=/tmp/empty-home ELANOUS_KEY_CACHE_DIR=/tmp/empty-cache \
  bun bin/elanous.mjs doctor

📏 그 상태의 실측:

rc = 0 · 164줄
resolved            0건      ← 자격 캐시까지 비웠으므로 「진짜 0」이다
unresolved         41건
Free fallback 줄   10줄      ← 자원 7개가 「키 없이도 되는 길」을 갖는다
잠긴 능력          이름으로 전부 나온다:  "<능력> — unlock with <KEY>"

⚠️ 함정: HOME 만 비우면 자격 캐시가 살아남아 resolved (cache) 가 찍힌다. 그러면 「키 0 에서 돌았다」가 아니다. ELANOUS_KEY_CACHE_DIR 를 빈 디렉토리로 같이 가리켜야 한다. ⛔ 캐시를 지우지 마라 — 같은 기계의 다른 작업이 쓴다.

codex 가 소진되면 어떻게 되나​

계정 자동 회전이 기본 ON 이고(llm.codexAccountRotation !== false), 쓸 계정이 하나도 없으면 폴백 체인으로 샌다. 새려면 셋이 동시에 참이어야 한다 — ⑴ codex 가 no-candidate ⑵ 체인에 grok ⑶ grok 자격이 있다.

⛔ 「grok 으로 새나」를 코드 기본값으로 읽지 마라. 이 인스턴스에서 재라:

elanous config get llm.fallbackChain
elanous usage          # 계정별 잔량

하니스를 어디로 쏘나​

elanous harness say "이 파일의 테스트를 붙여라"      # 터미널에서 한 줄
elanous harness ask docs/goals/MY-ASK.md            # 골 문서를 이미 썼다면

문 목록을 재고 싶으면 elanous self entrances.

얼마나 큰가​

최상위 명령 69 · 하위 507 ⇒ 잎 약 576 · 도움말은 69/69 가 rc=0

📏 bun scripts/gen-docs-cli-reference.ts 가 이 수를 그때 다시 잰다.

TUI 가 주 인터페이스인가​

아니다. 3-pane TUI 는 계보상 한 단계였고(sync-skills → skillpad → TUI 섀시 → 지금), 지금의 축은 하니스 · PTY 컨트롤 · 제1원칙(관측→자기인지→셀프힐링) 이다. TUI 는 여러 표면 중 하나로 계속 돈다(CLI · NEXUS/PWA 대시보드 · MCP · 채팅 채널과 나란히).

무엇이 유료인가 — 없으면 무엇이 안 되나​

세계를 보는 「눈」의 상당 부분이 외부 서비스에 얹혀 있다. catalog/resources.yaml 이 항목마다 「없으면 어떻게 되나」를 free_fallback 으로 적는다.

항목 30 · 자격이 필요한 것 27 · auth=none 3
free_fallback 이 적힌 것 7  ⇒ ⚠️ 나머지 20은 «그 칸이 비어 있다»

⚠️ 그리고 맵이 「API 키」만 센다. omni-crawl · aside · CDP/Chrome 은 항목이 «없다» — 「깔려 있어야 하는 바이너리·브라우저」라는 의존의 한 종류가 아직 안 실렸다. ⇒ 무료 폴백이 «적혀 있는» 능력만 「코어」로 믿어라. 나머지는 안 쟀다는 뜻이다.

다른 저장소에도 쓸 수 있나​

아직 아니다. 하니스가 여러 자리에서 이 저장소를 전제한다 — 기본 정합 게이트가 bun bin/elanous.mjs --help 를 돌리는데 남의 프로젝트엔 그것이 없다.

설치부터 첫 골까지 사람 손이 몇 번인가​

현재 실측 5번 — ⑴ 설치 ⑵ elanous login openai-codex ⑶ elanous config set llm.provider … ⑷ codex login ⑸ elanous harness say. 목표는 3번 이하이고 줄일 후보는 ⑶ 이다. ⚠️ 이것은 «명령 수»를 센 값이다 — 빈 기계에서 실제로 세지는 않았다(다른 값일 수 있다).
