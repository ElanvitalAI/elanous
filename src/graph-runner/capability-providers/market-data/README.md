# Contract market-data providers

Graph capability nodes name a `requires` contract and provide `market`, `symbol`, and, for daily bars, `from` and `to`. Provider declarations supply `provides`, `tier`, measured or estimated `latency`, source attribution, and market conditions. Fixed HTTP responses exercise every adapter without live requests. The normalized result includes its source and observation time; credentials and raw responses are not returned.

| Provider | Contracts | Credential | Operational and usage note |
| --- | --- | --- | --- |
| FRED | rates, macro | `FRED_API_KEY` (legacy `keyEnv`) | Free registration key required. [FRED API terms](https://fred.stlouisfed.org/docs/api/terms_of_use.html) require a visible nonendorsement notice and preserve underlying third-party data rights. |
| Bank of Korea ECOS | rates, macro, fx | `ECOS_API_KEY` (legacy `keyEnv`) | [ECOS introduction](https://www.bok.or.kr/portal/bbs/B0000522/view.do?menuNo=201692&nttId=10070977) directs developers to register a key. Confirm redistribution rights before public display. |
| Upbit | crypto | none | [Quotation API](https://docs.upbit.com/kr/reference/api-overview) is public and unauthenticated; respect request limits. |
| CoinGecko | crypto | none | [License guidance](https://support.coingecko.com/articles/1043089972-what-are-the-differences-between-commercial-and-custom-licenses) distinguishes free personal from commercial rights. |
| Finnhub | US quote, daily OHLCV | `cred:finnhub.api_key` | [Terms](https://finnhub.io/terms-of-service) restrict personal plans and redistribution. Confirm free candle entitlement with the user's plan before live use. |
| Korea Investment & Securities | KR quote, daily OHLCV, investor flow | `cred:kis.app_key`, `cred:kis.app_secret` | [API portal](https://apiportal.koreainvestment.com/intro) and [official examples](https://github.com/koreainvestment/open-trading-api/tree/main/examples_llm/domestic_stock) document read-only quotation access. [Provider guidance](https://apiportal.koreainvestment.com/provider-info) flags separate data agreements for third-party display. The single OHLCV response is bounded to 100 calendar days. |
| EODHD | US/KR quote, daily OHLCV | `cred:eodhd.api_key` | [Live quote](https://eodhd.com/financial-apis/live-ohlcv-stocks-api) is delayed about 15–20 minutes for stocks; [EOD history](https://eodhd.com/financial-apis/api-for-historical-data-and-volumes) is daily. Free-plan coverage and personal-use limits vary by symbol and endpoint. |
| Toss Securities | US/KR quote, daily OHLCV | `cred:toss.client_id`, `cred:toss.client_secret` | [Market-data guide](https://developers.tossinvest.com/docs/market-data) documents OAuth-only read access, separate quote/chart rate-limit groups, and 200-candle pages. [Auth guide](https://developers.tossinvest.com/docs/auth) says only one token is valid per client; this adapter shares the existing token cache. No account or order endpoint is called. |
| Twelve Data | US quote, 5-minute intraday bars | `cred:twelvedata.api_key` | Uses the existing omni-market skill's quote/time_series paths. US stock symbols only; plan entitlements and redistribution terms must be checked before public display. |
| Financial Datasets | US quote, daily OHLCV, company facts | `cred:fds.api_key` | Uses snapshot, prices, and company facts with the provider's `X-API-KEY` header. Company facts retain the provider field names; confirm plan rights before external reuse. |
| Yahoo Finance | index and continuous-futures quote | none | Public chart endpoint, no service guarantee; check Yahoo usage terms before commercial display. |
| KRX Data Marketplace | 14 read-only daily API IDs | `cred:krx.api_key` | Routes follow OP's kr-flow specification, including KOSPI and KOSDAQ stock-info IDs. The source sends `AUTH_KEY` as a URL query parameter. Each service requires separate approval; `OutBlock_1` rows retain source fields. See [KRX terms](https://openapi.krx.co.kr/contents/OPP/INFO/OPPINFO002.jsp). |
| pykrx | KR daily OHLCV fallback | none | Optional local Python package; no request unless selected. Check underlying KRX data rights before redistribution. |

EODHD uses `tier: byok`; Toss, KIS, and Finnhub use `tier: free` with secret-store credential references. The registry selects an available provider by tier and latency. `graph run` and graph ticks install this registry by default, but no request occurs until a matching contract node executes. ECOS pages through a bounded monthly window and rejects ambiguous symbols; FRED skips missing latest observations. KIS quote `asOf` is the adapter observation time, while investor flow uses the provider's date. The optional `cred:kis.account` slot is not needed for market-data reads.

## One-time migration for OP

Run `bun scripts/migrate-omni-market-secrets.ts` on the machine with the existing skill `.env` files. It reads the omni-market and kr-flow skill `.env` files plus the configured Conatus `.env` location; positional file paths override those defaults. It maps EODHD, Toss, Twelve Data, FDS, KIS, KRX, and Finnhub key names, reuses the `eln secret` parser and credential-slot writer, refuses existing slots, and prints only imported slot names. `KIS_MODE` is validated separately and saved as `kis.mode` in `~/.elanous/market-data.json`; the output reports the setting name only. Source `.env` files remain because existing skill code still consumes them; retire those files after migrating and verifying those skills separately. OP executes the command, not this PR. The full nine-source and kr-flow command mapping is in [INVENTORY-1109.md](INVENTORY-1109.md).
