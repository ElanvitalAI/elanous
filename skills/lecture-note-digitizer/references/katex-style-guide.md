# KaTeX 수식 스타일 가이드 — 강의노트/가이드 공통

> 이 파일은 마크다운 작성 시 수식을 KaTeX LaTeX로 감싸는 패턴 레퍼런스.
> 가이드 v2 (148개 인라인 수식)에서 추출한 모범 패턴 모음.

## 원칙

1. **변수명 2개 이상 포함된 표현은 예외 없이 `\(...\)` 감싸기.**
2. **`$$` 블록 수식 사용 금지** — Typora에서 렌더링 깨짐. 대신 `> \(...\)` (blockquote + 인라인) 패턴 사용.
3. Python `markdown` 라이브러리가 `\(` → `(` 로 먹으므로, HTML 변환 시 플레이스홀더 보호 필수.

## 패턴별 예시 (Good vs Bad)

### 1. 본문 서술 속 짧은 수식 참조

```
❌ 이것이 MB = MC의 변형입니다
✅ 이것이 \( MB = MC \)의 변형입니다

❌ 최적 선택 조건(MRS = Px/Py)을 이해하는 데
✅ 최적 선택 조건(\( MRS = \frac{P_x}{P_y} \))을 이해하는 데

❌ P > AC이면 초과이윤
✅ \( P > AC \)이면 초과이윤
```

### 2. 볼드/강조 안 수식

```
❌ **MU > 0** — 다다익선
✅ \( MU > 0 \) — 다다익선

❌ **MRS = Px/Py**
✅ \( MRS = \frac{P_x}{P_y} \)
```

### 3. 테이블 셀

```
❌ | MB (한계편익) | X재 소비의 주관적 가치 = **MRS** |
✅ | \( MB \) (한계편익) | X재 소비의 주관적 가치 = \( MRS \) |

❌ | MR = P |
✅ | \( MR = P \) |
```

### 4. 제목/소제목

```
❌ ### MB = MC 해석
✅ ### \( MB = MC \) 해석

❌ ## 5.3 소득주도성장과 한계소비성향 (MPC)
✅ ## 5.3 소득주도성장과 한계소비성향 (\( MPC \))
```

### 5. 괄호 안 수식 참조

```
❌ 가정 1(MU > 0)
✅ 가정 1(\( MU > 0 \))

❌ 가정 2(MU 체감)
✅ 가정 2(\( MU \) 체감)
```

### 6. 블록인용 공식 — "직관 먼저, 공식 나중" 패턴

가이드 v2 스타일: 한 줄 설명 + blockquote 수식 + 부가 설명

```markdown
**14. 노동자를 한 명 더 뽑으면?**
추가로 1명을 고용했을 때 늘어나는 생산량이 한계생산입니다.
> \( MPL = \frac{\Delta Q}{\Delta L} \) (한계생산)
```

### 7. 첨자 변수는 단독이어도 감싸기

```
❌ X재의 한계효용 MU_x는
✅ X재의 한계효용 \( MU_x \)는

❌ 가격 P_x가 하락하면
✅ 가격 \( P_x \)가 하락하면

❌ MPC가 낮은 고소득층
✅ \( MPC \)가 낮은 고소득층
```

### 8. 단계별 풀이 (Step-by-Step)

```markdown
\( U(x, y) = x^{0.5} \cdot y^{0.5} \)일 때 한계효용:

**Step 1**: \( MU_x = 0.5 \cdot x^{-0.5} \cdot y^{0.5} \)
**Step 2**: \( MU_y = 0.5 \cdot x^{0.5} \cdot y^{-0.5} \)
**Step 3**: \( x \)가 커질수록 \( MU_x \)는 감소 → 한계효용 체감 확인
```

## 자주 쓰는 수식 변환 테이블

| Plain text | LaTeX |
|-----------|-------|
| `MU_x` | `\( MU_x \)` |
| `MRS = MU_x / MU_y` | `\( MRS = \frac{MU_x}{MU_y} \)` |
| `Px * x + Py * y <= I` | `\( P_x \cdot x + P_y \cdot y \leq I \)` |
| `MRS = Px/Py` | `\( MRS = \frac{P_x}{P_y} \)` |
| `MU_x / P_x = MU_y / P_y` | `\( \frac{MU_x}{P_x} = \frac{MU_y}{P_y} \)` |
| `MB = MC` | `\( MB = MC \)` |
| `P = MC` | `\( P = MC \)` |
| `MR < P` | `\( MR < P \)` |
| `P > AC` | `\( P > AC \)` |
| `SW = CS + PS` | `\( SW = CS + PS \)` |
| `epsilon_P` | `\( \varepsilon_P \)` |
| `dU/dx` | `\( \frac{dU}{dx} \)` |
| `partial U / partial x` | `\( \frac{\partial U}{\partial x} \)` |
| `x^0.5` | `\( x^{0.5} \)` |
| `sqrt(x)` | `\( \sqrt{x} \)` |

### 9. `\text{}` 안에 괄호 금지 — delimiter 충돌

KaTeX auto-render가 `\(` delimiter를 사용하므로, `\text{}` 안에 `(`가 들어가면 수식 파싱이 깨진다.

```
❌ \( \text{Value} = \frac{\text{Utility (고객의 지불 의사)}}{\text{Cost (생산·전달 비용)}} \)
❌ \( \text{Value} = \frac{\text{Utility}\;\text{(고객의 지불 의사)}}{\text{Cost}\;\text{(생산·전달 비용)}} \)  ← \;\text{( 도 충돌
✅ \( \text{Value} = \dfrac{\text{Utility — 고객의 지불 의사}}{\text{Cost — 생산·전달 비용}} \)
```

**규칙**: `\text{}` 안에서 괄호 `()` 를 사용하지 않는다. 괄호 대신 **em dash(—)** 로 대체. `\;\text{(` 분리 방식도 KaTeX delimiter `\(`와 충돌하므로 불충분.

## 체크리스트 (작성 완료 후)

마크다운 작성 후 아래 grep으로 누락 검사:

```bash
# Plain text 수식 후보 찾기 (LaTeX 밖에 있는 것)
grep -nE '(MU_[xXyY]|MRS|MB =|MC |P_x|P_y|MPC|MR =|AC |SW =)' file.md | grep -v '\\\\('
```

결과가 0이면 통과. Mermaid `%%` 주석, 노드 텍스트는 예외.

## 실전 함정 2건 (2026-09, BIZ503 3주차에서 물림)

### 1. `$$` 를 정규식으로 짝짓지 말 것 — 한 줄짜리 하나에 전부 밀린다
`> $$x$$` 처럼 **한 줄에 여는/닫는 `$$` 가 같이 있는** 블록이 하나라도 있으면,
`\$\$\n(.*?)\n\$\$` 류의 정규식은 그 다음부터 **여는 것과 닫는 것을 반대로 짝지어**
본문 문단이 통째로 수식(`\[ … \]`)이 되고 KaTeX 가 문단 전체를 에러로 뱉는다.

→ 정규식 대신 **`md.split('$$')` 후 홀/짝 인덱스로 페어링**한다. 구분자 개수만
짝수면 절대 밀리지 않는다. (`note_pipeline.normalize_math`)

### 2. 구분자만 보호하면 markdown 이 수식 '내용' 을 먹는다
`\(`/`\)` 만 플레이스홀더로 치환하는 것으로는 부족하다.
`\underbrace{i}_{(-)}, \underbrace{Y}_{(+)}` 는 `_..._` 가 `<em>` 으로 변환되며
**언더스코어가 사라진다**. `*`, `_`, 백틱이 모두 수식에 등장하므로
**수식 span 통째로** 플레이스홀더로 빼둔 뒤 HTML 변환 후 복원해야 한다.
(`note_pipeline.stash_math_spans` / `restore_math_spans`)

### 3. 금액 가드(`$` 뒤 숫자 제외)는 진짜 수식도 같이 막는다
`$1.05 \times 1.02 = 1.071$` 은 `$` 뒤가 숫자라 인라인 수식 변환에서 제외된다.
→ 1차 변환 후 **내용에 백슬래시(LaTeX 명령)가 있는 경우만** 2차로 구제한다.
`$700bn`, `$1,200` 은 백슬래시가 없으므로 안전하게 그대로 남는다.
