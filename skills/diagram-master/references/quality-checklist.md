# Anti-AI 품질 체크리스트

다이어그램 생성 후 반드시 검증. (markdown-viewer/skills infocard 참고)

## 필수 검증 항목

### 레이아웃
- [ ] **균등 타일 금지** — 모든 박스가 같은 크기/같은 간격이면 AI 냄새. 의미에 따라 크기 차등
- [ ] **중앙 정렬 hero 금지** — 비대칭 레이아웃이 더 자연스러움
- [ ] **수학적 정밀 간격** — 눈대중이 아닌 일관된 spacing 시스템 사용

### 색상
- [ ] **순수 검정(#000000) 금지** — off-black 사용 (#1a1a2e, #0f172a 등)
- [ ] **네온 그라디언트 금지** — AI glow 느낌 배제
- [ ] **시맨틱 색상** — 의미에 맞는 색상 사용 (성공=녹색, 경고=주황, 오류=빨강)
- [ ] **단일 색상 팔레트** — 한 다이어그램에서 색상 소스 통일

### 콘텐츠
- [ ] **필러 데이터 금지** — "99.99%", "50%", "Lorem ipsum" 등 AI 생성 느낌
- [ ] **AI 용어 금지** — "empower", "seamless", "unleash", "cutting-edge" 자제
- [ ] **Evidence Artifacts** — 실제 코드, 실제 데이터, 실제 이벤트명 사용
- [ ] **Isomorphism Test** — 텍스트를 제거해도 구조만으로 개념 전달 가능한가?

### 기술적
- [ ] **렌더링 검증** — 생성 후 반드시 PNG로 렌더링하여 시각적 확인
- [ ] **한글 깨짐 확인** — 한글 폰트가 올바르게 적용되었는지
- [ ] **수식 렌더링 확인** — KaTeX/mathtext 수식이 깨지지 않았는지
- [ ] **해상도 적절성** — scale/DPI가 충분한지 (인쇄용 300 DPI, 웹용 150+ DPI)

### 대형 다이어그램
- [ ] **섹션별 빌드** — 한 번에 전체 생성하지 않고 섹션 단위로 점진적 구축
- [ ] **노드 30개 초과 시 분할** — 하나의 다이어그램에 너무 많은 노드 금지
- [ ] **시각적 계층** — Overview → Detail 멀티줌 구조
