# 0.2.5

Plus 326 internal changes.

## Known issues

0.2.5 ships with a few known issues. None of them affect installing, starting or updating Elanous, running the harness, or your data. Fixes are planned for 0.2.6.

- Sub-agents reuse the prompt cache less often than in 0.2.4, so they may use slightly more tokens.
- Some `elanous control` commands show an unclear message and exit code on a machine that has not joined a control plane.
- Some log lines can appear twice.
- A few internal checks in our own test suite fail in this release. They do not change how Elanous behaves.
