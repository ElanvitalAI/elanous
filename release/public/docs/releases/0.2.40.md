# 0.2.40

## Behavior changes

- In the classic TUI, you can switch conversations with side tabs, create new shells, or connect and disconnect local terminals. Target: next. (#31436, #31507, #31614, #31629, #31997)
- Web search uses the Grok subscription as the default route, and enabling a paid search provider in settings makes that route available as well. Target: next. (#31805)
- Conveys work boundaries, decisions, and overlapping PR context alongside code reviews so that project standards are reflected in the review. Target: next. (#31709)
- In classic TUI `Ctrl+\`Pressing it no longer exits the app and instead shows the side tab guide. Target: next. (#31903)
- Distinguishes Codex's intermediate progress responses from its completion signal so the final response isn't missed. Target: next. (#31949)
- Long-running or canceled skill executions return a failure result so the conversation can continue to the next decision. Target: next. (#31968)

Plus 164 internal changes.
