# 0.3.14

This urgent patch restores local Codex login for standalone installations without a configured fleet credential owner. Next TUI and other chat paths use the same decision: a standalone user reads the local Codex login; a host explicitly configured for an owner's access-only mirror keeps that boundary.

The patch also includes the 0.3.13 Next TUI conversation repair, the 0.3.12 startup fixes, and built PWA files. Before publication, an isolated installation with one Codex CLI login and no mirror completed three consecutive Next TUI replies, a reply after /new, and real PWA chat replies. The broader feature release is planned as 0.3.15.

Installers and assets are available from the [v0.3.14 release](https://github.com/ElanvitalAI/elanous/releases/tag/v0.3.14).
