# Elanous 0.3.29

- In a small Next terminal, the command list fits the rows that are left, starts with /help, and the input stays visible.
- In the Next terminal, a slash-command answer or notice longer than the screen now wraps instead of being cut off at the edge.
- In the Next terminal, /session and /resume show «New chat» for a saved chat without a title, as the header does.
- In web chat, typing /new starts a new chat session instead of sending the text as a message.
- In web chat on your Nexus, a one-line app build now fills in your verified member app address, as the terminal already did; before, it stopped and asked you to connect.
- If a model keeps streaming without producing any answer for 10 minutes, the turn now moves on to the next provider instead of staying at «Responding»; a silent OpenRouter model first tries your other configured OpenRouter model once.
- Running `els` inside an Elanous Side pane now says so and exits, instead of starting a nested workspace.
- In Elanous Side, `els workspace move` and `els tab move` reorder spaces and tabs, and `els ls` lists them in that order.
- In the Next terminal, the queue panel header now says «Enter edit», matching what Enter does there.
- In the Next terminal, the input has breathing room: blank rows and a thin separator now sit under it.
- Pressing Esc now also stops a running Bash command or agent call, not only the reply.

## Perf

- While idle, the side tab no longer rewraps the whole conversation on every tick.

## Security

- Web chat's debug view is off by default, opens only for the owner's connection, shows only its own session, and is size-limited.

## Known issues

- The full pre-release test sweep for this version did not finish before publishing; some failing checks in internal test harnesses remain and are tracked for the next release.
- In the web app, three checks on the intake page (actions disabled for an empty field, URL previews absorbed without submitting, and classification offered for an unknown rule without calling a model) did not pass in the release test run and are tracked for the next release.
