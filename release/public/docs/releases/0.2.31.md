# 0.2.31

## Behavior changes

- External `/stop` and `/esc` requests now bypass queued input and reach the active turn's escape gate. PR: #28724.
- Task Agent repair launches can carry an explicit dispatch tier and use subscription availability for model selection; older task cards remain compatible. PR: #27786.
- `/session new` refreshes the boot card before asynchronous ACP renewal, keeping the card in sync when conversation history is cleared. PR: #28746.
- Legacy loop warnings no longer appear on CLI standard error. PR: #28432.

Plus 203 internal changes.

## Known issues

The following issues are known in this release.

- Release verification may take longer than expected after small changes because some checks can run again instead of reusing earlier results.
