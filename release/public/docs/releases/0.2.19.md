# 0.2.19

## Behavior changes

- `elanous guardian tick` and `elanous guardian compare --day <YYYY-MM-DD>` add a shadow-only cron guardian that records which scheduled jobs would run now and compares a day's expected fires with recorded runs, without running any job or touching crontab.
- `elanous tasks hand --completion <kind>` declares how a task finishes (code-pr, artifact, research-report, ops-action, content, watch-brief, decision-support); non-code tasks close on confirmation evidence instead of waiting for a merged PR.
- `elanous tasks hand --project <id> --target <dir>` points a task at a project folder that need not be a git repository (non-code completion kinds only) and launches it from that folder.
- Topics you pick at first setup now become personal watch sources, collected at 07:00 and briefed to your report channel at 08:30 by default (opt out with `watch.enabled=false`); a quiet day sends a one-line «no news today».
- The PWA release page draws the selected release run as a node flow (done, failed, now, remaining — with words as well as colours, per-node times when recorded, and gate shard progress), and tapping a node opens its full summary and log tail.
- `elanous tasks board [--project <id>] [--json]` shows a project › goal › milestone › task board built from task cards (`tasks hand --goal/--milestone`) and, read-only, the internal release checklist.
- Task cards record the run, goal and PR they led to (shown by `tasks show`), and mission advance uses a bound PR as evidence without `--pr`.
- In the TUI, `/now` shows running harness and release runs, late schedules and the current release in KST; `/decide` lists open decision cards and answers by number (irreversible categories ask for one confirm); `/help` is grouped into start · seven verbs · other; `/model 빠름|보통|깊음` picks a tier; `/status` speaks plain words by default (`--debug` for detail); Esc closes an open picker or modal first; in an isolated universe `dev --elanous` creates its own worktree when no `--cwd`/`--worktree` is given.
- TUI chat routes lookup, settings, research and scheduling questions to a quick single turn with matching tools instead of the coding goal loop.
- `elanous away on|off|status` (and Telegram `/away`) turns on away mode: while you are away every release-run node transition, gate result (introduced count and any waiver), block with the next move, and completion is sent to Telegram, with a one-line heartbeat every 60 minutes; blocks go out even in quiet hours. Telegram `/release` shows the current run and node on demand.
- The release gate's Pod shards count only the gate's own Jobs against its pool cap again, so the gate fans out instead of launching one shard at a time while goal Pods fill the cluster.

The following issues are known in this release.

- In the TUI, `/help` prints the help into the chat history instead of opening an overlay, so Esc does not dismiss it. Keep typing in the input line as usual; the help simply stays in the scrollback.
