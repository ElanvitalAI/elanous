# 0.2.32

## Behavior changes

- The TUI can wake for a completed child while idle, show background job counts, and schedule its own next turn. PRs: #28892, #28743, #28742.
- Reusable warm Pods are available as an opt-in transport, with request cleanup between uses. PRs: #28292, #28727.
- External `/stop` and `/esc` requests reach the active turn's escape gate immediately. PR #28769.
- Task Agent repair launches accept an explicit dispatch tier and select models using subscription availability. PR #27786.
- The TUI shows when a fallback model answered and keeps the session boot card current after history reset. PRs: #28734, #28746.
- PWA live run graphs show the current execution graph. PR #28879.
- TUI click-to-fold controls can be toggled back open in place. PR #28825.
- The TUI detects a doom loop and changes approach without asking, and avoids false “NO FINAL SYNTHESIS” after a goal loop has ended. PRs: #28795, #28772.
- Resizing the terminal preserves the open slash picker border; folding panes preserves their position. PRs: #28766, #28825.
- Long `RunShell` sleeps explain how to schedule a wakeup, and CLI legacy loop warnings no longer pollute standard error. PRs: #28763, #28432.
- Background input wakeups, PTY state reporting, and session tool traces now reflect the active turn more reliably. PRs: #28750, #28740, #28741, #28876, #28882.
- Task Agent closes stale drafts after a code PR opens and retries completed no-change children once. PRs: #28829, #28824, #28813.
- The PR tool warns on overlapping changed lines while allowing a new PR to open. PR #28881.
- Webclone reads ruler versions portably on Linux. PR #27855.
- Internal marker text is escaped from the public test export. PR #28754.

Plus 103 internal changes.
