# 0.3.5

## Behavior changes

- Pick a sentence in the aside browser and say "add this to the memo" to add it to the current memo with its source.
- The plugin wizard starts two coding-agent side tabs with separate briefs and workspaces.
- Show elapsed progress and cancellation guidance while the subscription device login waits during headless first-run setup.
- Simulation Special: rehearse agent and infrastructure automation in a fake world with real Elanous code and fake boundaries. Creating and deleting a world takes seconds, not minutes, and involves no real servers or accounts.
- Save, restore and fork a simulated world with `eln sim world snapshot`, `restore` and `fork`, then run each branch separately and compare the results.
- Declare faults in `world.yaml` and watch whether the system recovers: kill a process (monkey) or take a host down (gorilla).
- Inject any catalogued event into a simulated world through the same write path as production, marked as injected and refused in the real universe.
- The public Simulation Kit ships a world format, YAML scenario guide, device catalog, CLI and example worlds. Start with `eln --test sim devices`.
- New simulated devices for fetch, binaries, app hosting, app sign-in, speech and video providers, plus a secret canary check.
- Replayed-versus-device fidelity checks and a coverage report show which code paths, events and devices the simulation reaches.
- Install with one line: `npm i -g elanous` sets up Bun, initial configuration and doctor.
- First-run setup uses a detected coding-agent subscription without asking for an API key.

Plus 165 internal changes.

## Known issues

The following issues are known in this release.

- There is no user-visible impact.
- A release verification test used an outdated command pattern. Product behavior is unaffected.
