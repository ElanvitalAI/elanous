# 0.2.36

## Behavior changes

- Continue bounded remaining work in the TUI, yielding when new input or a human decision is needed. (#30657)
- Route larger goal work through subagents when delegation is appropriate. (#30617)
- Record doctor visits for long-running work and transitions that need owner attention. (#30403, #30468, #30608, #30618)
- Improve first-run onboarding for Korean and English users and guide new users toward a first useful result. (#30536, #30646)
- Connect Software Wizard requests to the actual run path. (#30668)
- Stop the release workflow when npm publishing fails. (#30677)
- Verify accepted gate-radius receipts and fail closed when a receipt does not match. (#30678)

Plus 204 internal changes.
