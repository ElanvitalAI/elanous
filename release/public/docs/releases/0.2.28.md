# 0.2.28

## Behavior changes

- Failed reviews can launch a bounded commit-only repair on the same PR branch with exact-head protection and owner notification.
- Seat messages can stream from a separate authenticated SSE post office, with durable replay and polling fallback.
- `eln pr land --cwd` now reads TypeScript gate inputs from the selected worktree and finds an installed compiler before running; missing compiler dependencies fail with an install hint.
- Seat messages can link replies, wait for the first answer with an explicit sender, and display ordered threads.
- Explicit child rework escalation can use an optional same-provider model map, with env precedence and an observed target decision.
- Telegram briefings now collect item button and reply feedback, order measured topics by weekly action rate, and keep incomplete split items eligible for retry; delivery remains at least once.

Plus 103 internal changes.
