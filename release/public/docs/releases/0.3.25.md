# Elanous 0.3.25

- Ask Elanous in one line to build an app: it writes down its assumptions, designs the architecture in the language you asked in, chooses how to test the app, writes and tests the files in a private space, and publishes only after you approve.
- Apps you choose to make public can be viewed in any browser without signing in. Actions that change data, such as booking, still need a signed-in member.
- In the terminal, answers now grow from the top of the screen, keep their paragraphs when Elanous uses several tools in a row, and show the first Korean characters sooner.
- Typing exit, quit, 종료 or 그만 in a terminal chat no longer ends the session; only an explicit slash command does.
- When you say “here” or “this folder”, Elanous now uses the folder you are working in and knows its Git root and branch.
- Elanous finds the right tool more reliably when a Korean request joins words together.
- If connecting your app address key fails, you stay signed in and can try again.
- When a terminal turn fails, the message now explains that pressing Up brings your text back so you can send it again.

## Known issues

- A full sign-up with a real Google account on the release build has not been measured yet.

- Release gate testing is incomplete. Remaining checks are deferred to follow-up verification.
- Two startup and cleanup checks also fail in the previous release. Their user-facing impact remains unverified.
