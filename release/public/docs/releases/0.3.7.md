# 0.3.7

## Behavior changes

- Upload an app and keep its files in per-app storage, with temporary sign-in for the people who open it.
- Call speech-to-text summaries, text-to-speech and generation jobs from inside an app.
- Reach an app from outside through the public relay mode and host connection, and manage apps from the terminal with the new app CLI.
- Every deploy keeps a snapshot of the app source, so you can roll back to the previous version.
- Shared credential slots let several features use the same credential from one place.
- Fixed `eln machine` stopping right at startup on Windows.
- Fixed several defects in release verification and internal workflows.

Plus 263 internal changes.
