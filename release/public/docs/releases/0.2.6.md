# 0.2.6

## New

- `elanous plugin make "<request>"` writes a local graph plugin from one sentence, checks its shape, installs it and can run it right away (`--run`).
- The terminal dashboard now tells you when Elanous was updated underneath it and asks you to restart it.
- Nodes from installed plugins now appear in the web workflow editor's palette without restarting the daemon, even when no MCP server is configured.

## Fixes

- Running several `elanous ask` commands at the same time no longer fails or loses sessions from the session list.
- `elanous ask --json` prints only JSON on standard output, including on machines where no notification channel is set up.
- `elanous harness stop` finds a run's launcher process even when the orchestrator record is missing, and says what it looked at instead of reporting «no process».

Plus 75 internal changes.

## Known issues

0.2.6 ships with a few known issues. None of them affect installing with the one-line installer, starting or updating Elanous, running the harness, or your data. Fixes are planned for the next release.

- If you install with `npm i -g elanous`, install Bun first — on a machine without Bun the `elanous` command cannot start in this release. The one-line installer is not affected; it sets up Bun for you.
- Two more marketer plugins, card-followup and video-explainer, are not in the official market yet. They will be listed in a follow-up update.
- A few internal checks in our own test suite fail in this release. They do not change how Elanous behaves.
