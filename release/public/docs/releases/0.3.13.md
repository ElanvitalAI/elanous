# 0.3.13

This focused patch repairs a Next TUI conversation that could fail after its first reply in 0.3.12. The sticky chat child now retains the selected instance root for subsequent turns and starts with that root.

The 0.3.12 startup fixes and built PWA files remain included.

## Known issue

A standalone installation with a local Codex login and no configured fleet credential owner can incorrectly require an access mirror. This affects the first Next TUI turn and PWA chat. The behavior is also present in earlier releases and is fixed in [0.3.14](0.3.14.md).

Installers and assets are available from the [v0.3.13 release](https://github.com/ElanvitalAI/elanous/releases/tag/v0.3.13).
