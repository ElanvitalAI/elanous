# 0.3.33

## Behavior changes

- When the operations coordination session begins, it recalls previous memories and works with a tone and guidance tailored to the coordinator.
- The goal set by a person is fixed, so notifications arriving mid-way cannot change it. The fixed marker stays visible even on narrow screens.
- Important messages can interject even while a response is in progress, and instead of repeatedly checking for results, the system waits for them to arrive.
- Multiple notifications are batched and processed together, and when background work finishes, the idle spot is woken up once.
- The tab name appears first in the Elanous Side tab bar, and new tabs open in the working folder of the current window.
- Lines typed during a conversation and the number of pending entries are now shown directly on screen.
- RunShell script mode supports signed recipes, revocation handling, an expanded read-command allowlist, and execution after approval.
- The Smart Router is now available in Free, Pro, and Advanced plugin tiers, and Quality Guard monitors the quality of lightweight models.
- All LLM calls are logged in the cost ledger, and you can view per-seat token usage and spike alerts.
- The work goal document is written in a five-field format, and blank fields are checked upon receipt.
- Connections of previously open tabs are maintained even when the Elanous Side server is restarted.
- Cleans up orphaned server processes and safely preserves windows restored to a missing working folder.
- Fixed an issue where account execution was switching to a different account.

## Security

- Secret values in RunShell output are masked before being passed to the model.
- Security audit events, such as rejected inputs and approval records, are logged immediately.
- When sharing memories to another chat, sharing is denied by default and only a summary is delivered.

Plus 124 internal changes.
