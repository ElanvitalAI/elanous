# 0.2.18

## Behavior changes

- `elanous release run` now cuts each release on its own `release/<version>` branch, so work on main keeps landing while a release is being published; `elanous release resume` continues a failed release run from a repaired branch.
- `elanous release run --prerelease rc` publishes a release candidate (`<version>-rc.<n>`) to npm `next` and as a GitHub pre-release, leaving `latest` on the current stable release.
- `elanous tasks hand --mission` splits a mission into piece cards with precedence and hands the ready pieces to the task agent; `elanous tasks show <mission-id>` lists the pieces and their edges.
- `elanous tasks advance` hands the next mission piece once its predecessors' PRs are merged (evidence recorded with `--pr`/`--goal`) and proposes the cell green when every piece has landed, without changing the checklist.

Plus 93 internal changes.
