# 0.2.13

## Behavior changes

- Seat packs export seat charters, referenced loop graphs, verdicts and default budgets with a SHA-256 manifest after a pre-write public-leak check.
- The run graph editor now lets each node choose a failure destination, saved as the existing outcome `fail` edge in graph YAML.
- `elanous seat answer` records a CTO reply in the existing ask ledger and returns it to the originating Telegram chat and thread; unanswered asks receive a notice after two hours.
- `elanous agent-mission duo` runs Codex and Claude Code concurrently in separate worktrees, groups their PTY decisions by mission, and compares evidence and DRIVE-OK outcomes.
- Git test helpers and deterministic children clear inherited repository-location variables; the runner restores and fails on shared core.bare changes.
- A release gate judges completed Pod shards, including zero-test file errors, when a retried shard remains silent, recording its files as environment stalls and testing each once on the host.
- Release publish tests now use real auto-approval output, accepting added warning-only rows while rejecting missing blocking metrics.
- The internal ops feed installs tag-local frozen dependencies when the tag and main differ, instead of building the tagged PWA with main's dependencies.
- Telegram `아크:` messages create a daemon-backed fabric plan draft with step previews and approval/edit buttons; execution remains gated on approval.
- Hold host Pod leases from goal authoring until the Job's Pod is Running or terminal, and show authoring reservations separately from waiting Jobs and running Pods.
- Persona YAML now names each coworker's todo file; `elanous persona loop <name> --once` records the priority-and-deadline pick in shadow without executing it.
- `elanous steward readiness --since 24h [--json]` reads shadow-tick decisions, hypothetical actions, planning cost estimates and human-confirmation counts without changing state.
- Steward graph node processes now persist triage and schedule decisions to logs.db for `elanous logs` queries without changing routing.
- `elanous team validate <file>` checks a YAML team definition, persona references, and acyclic handoffs without running the team.
- TC records an ask-shadow in the existing seat ask ledger when its release judgment finds another seat's red cell, without dispatching a message.
- HQ fencing now prefers a host-local identity file over replicated config, fails closed on a damaged identity file, reports mismatches, and provides `elanous hq host set <name>` to write it.
- Ledger-writing release checklist and decisions CLI commands now respect the HQ lease generation, with an observed override and pre-lease bootstrap allowance.
- omni-crawl and omni-digest start with bun instead of npx tsx — about ten times faster to start and no download on a fresh machine — and say plainly which optional engine is missing.
- steward digest is sent as an operations report, not a trading report.
- Decision cards now open with a 30-second pitch — situation, problem, question, answer, the recommendation, one alternative, who cross-checked it and any dissent.

Plus 83 internal changes.
