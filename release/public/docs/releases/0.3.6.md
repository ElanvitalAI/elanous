# 0.3.6

## Behavior changes

- Simulated app traffic with a per-app cap and an admin kill switch, so you can rehearse a traffic spike without real users.
- Simulated app storage, DNS and certificate renewal, and a payment device, so app flows run end to end with no real provider.
- When a merge conflict only adds lines or table rows, the merge train now keeps both sides and re-queues the change instead of stopping.
- The type check passes again on a clean main, and a test fixture no longer trips the public export leak check.
- Retired the legacy autopilot, harness mission, and ops mission CLI entrypoints.
- Open an app tile to watch its simulation events and recent receipts.
- Manage each app's simulation and production environments from a single PWA tile, with create and trash actions.

Plus 193 internal changes.
