# 0.2.14

## Behavior changes

- `elanous hq promote --to <host>` previews the six-step HQ promotion without writing; `--apply` verifies the lease and standby checksums before copying into an isolated universe, starting nexus without MCP, and setting steward rescue; only one `--apply` runs per host at a time.
- Agent-mission DRIVE-OK no longer mistakes an `rg`, `grep`, or `diff` no-match tool exit for a failed mission when artifact evidence is verified; genuine final-answer failures still block success.
- Seat loops gain a live-safe mode (default stays shadow): it enqueues allowed goals through the harness queue with a per-item idempotency key, recovers an enqueue whose ledger row was lost to a crash, and refuses a same-key queue item carrying a different task instead of adopting it.
- `elanous release place` and `elanous release rebalance` place checklist cells by priority, merged-PR pace, seat limits and dependencies; a freeze window holds operational rollout but the release still exists and takes cells.
- Setting the ignored `ELANOUS_CONFIG_DIR` variable now prints one warning naming the config directory actually used and the `--config-dir` flag to use instead.
- the harness gate no longer treats a change to a test file plus docs as docs-only.
- `elanous loop status --all` now checks seat, cron-shell and orchestrator loops beside graph loops, uses the cron that is actually installed, and judges twice-a-day style schedules by their longest gap.
- the harness queue attributes running harness processes to seats by working tree on macOS and counts a parent and its child run once.
- a built-in YouTube summary graph turns a video transcript into a one-line verdict, key points and cards without external skills.
- when a harness run merges, older drafts of the same goal are marked superseded right away.
- the built-in YouTube summary falls back to speech-to-text when a video has no captions.
- `elanous harness goal <pr|runId>` shows the goal, run and outcome behind a harness PR in one view.
- `elanous loop list --all` shows every loop (graph, seat, cron-shell, orchestrator) in one table and warns about unregistered cron loops.
- the harness launch budget gate no longer blocks codex launches on subscription usage when the codex quota policy allows credits and a credit balance is confirmed.
- a Pod launch no longer dies when the host's grok subscription is about to expire: grok is dropped from that run's fallback chain with a warning and the run goes on with codex.
- `elanous flow tick` splits one Wish card into release cells, routes sensitive portions to owner decisions, and places safe cells with a read-only `flow plan <cardId> --dry-run` preview.
- the harness drops stale out-of-scope files that would silently revert recent main commits before committing a run's work.
- The youtube-master skill now runs on bun without tsx and says which optional engine (ffmpeg, yt-dlp, whisper) is missing instead of failing silently.
- the launch gate's duplicate-run check no longer gives up on old finished run ledgers without a goal id.
- the loop registry recognises hq-fence role wrappers and periodic elanous commands as named cron loops.
- the built-in YouTube graph can produce a study note (concepts, terms, steps and self-check questions).
- the harness gate looks at the whole run's changes before skipping tests for a source without paired tests, and flags the skip loudly.
- The "now" context view has a public-demo audience that folds internal items and hides seat codes, PR and run ids, host names and home paths.
- `harness say|ask --seat` stamps the seat into the run ledger so queue caps attribute runs correctly even outside a seat's working tree.
- the loop registry names cron jobs that run elanous via bun bin/elanous.mjs, and titles hq-fence wrapped lines by their inner command.
- the daemon's "now" endpoint serves a public-demo audience and enforces it in demo mode.
- the harness gate always runs the maturity-table tests when a change registers a slash, bot or CLI command.
- Pod harness kubectl calls no longer die with ENOBUFS on large cluster listings during OOM retry decisions.
- the loop registry recognises absolute-path eln cron jobs (including the loop checker itself) and never silently drops an elanous-related cron line.
- `elanous harness goal archive` previews finished goal documents and, with `--apply`, copies them to an indexed state archive and lists the repository files to remove in a PR (it never deletes or commits repository files).
- goal archive matches run ledgers by run id instead of absolute paths, and can optionally trust a goal document's own finished-run record.
- harness incident records name the entrance, seat, host and a redacted output tail, and burst warnings say whose burst it was.

Plus 129 internal changes.
