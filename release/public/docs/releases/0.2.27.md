# 0.2.27

## Behavior changes

- Seat boot now shows a read-only local handoff card from current seat sources.
- Self utterances now exports paginated, redacted human and agent speech by date, surface, and origin.
- `eln tasks hand --checklist` now uses the checklist title when no request text is supplied and rejects request text without a target path before launching a worker.
- `eln msg watch --since-ack` now explicitly reads a seat's unacknowledged messages without acknowledging them.
- The inside architecture view now follows the current product hierarchy of loop agents, graph engineering, wizard, and supporting runtime.
- `eln tasks hand --checklist` now finds cells across open release versions, with `--version` to select a specific release.
- The expose rubric CLI now checks public marketing blog drafts passed through `--files` for reproducibility, confidentiality, and brand fit before review.
- `eln tasks cover` now counts authored goals only after their goal run completes and merges, and marks unreadable ledgers as unknown.
- PR landing now accepts review result filenames with a 10 to 40 character commit prefix when the review content confirms the full PR head.
- `eln msg post --to ALL` now stores one broadcast message; each recipient reads it alongside direct messages with their existing acknowledgement cursor.
- Channel posts now mirror addressed messages into the durable inbox, and seat boot shows each seat's unread message count.

Plus 92 internal changes.
