# 0.3.12

This focused update addresses four startup problems in 0.3.11.

- Next TUI can open when a provider is authenticated and ready, even if optional web or Telegram onboarding is incomplete. First-time setup remains for a provider that is not ready.
- The PWA first screen no longer crashes with React error #310. The fix was checked in a real browser at a narrow viewport.
- Provider login respects an explicit configuration directory, so login and the following session use the same credential store.
- Next TUI shows a provider authentication error instead of waiting silently when the first turn cannot authenticate.

The release package includes the built PWA files, so the web app can open on first start without a local build.

The broader feature release is planned as 0.3.15.

A standalone installation with a local Codex login and no fleet credential owner can incorrectly require an access mirror. This is fixed in [0.3.14](0.3.14.md). A separate Next TUI second-turn error is fixed in [0.3.13](0.3.13.md).

Installers and assets are available from the [v0.3.12 release](https://github.com/ElanvitalAI/elanous/releases/tag/v0.3.12).
