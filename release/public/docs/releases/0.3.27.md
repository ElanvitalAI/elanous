# Elanous 0.3.27

- Approved public apps can register their public routes automatically on hosts already trusted by the relay.
- App-building workflows can collect sources in parallel, review architecture, and retry bounded repairs before asking the owner to publish.
- Workflows can fill missing preconditions within a bounded budget and check postconditions before continuing.

- Workflows validate credentials for the plugin that is actually running.

- Release notes now describe the latest app-building improvements.

## Known issues

- A complete first-run ticketing scenario on this release has not yet been independently measured.
- The full release gate was not run; this release follows an approved manual critical path.
