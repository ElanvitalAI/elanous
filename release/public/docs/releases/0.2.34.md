# 0.2.34

## Behavior changes

- The TUI explains turn progress, shows concise reasoning summaries, groups internal tool activity, and flushes a pending explanation when a turn ends with an error. PRs: #28961, #28964, #28966, #28968.
- Task Agent work orders carry completion boundaries through decomposition, retries follow the next-move graph, and called units receive prior results. Landing refusals can use a read-only recovery route. PRs: #29075, #29085, #29093, #29106, #29109, #29113.
- Common read-only CLI queries use a lighter startup path; `config get` and `msg watch` are available through lightweight commands. PRs: #29094, #29099.
- The PWA adds an operations overview. PR: #29144.
- You can install a local plugin from the dashboard. PR: #29572.
- OpenRouter model detection now shows measured Upstage models. PR: #29574.
- Grok subscription expiry can raise an alert. PR: #29081.

Plus internal fixes, test coverage, and documentation updates.
