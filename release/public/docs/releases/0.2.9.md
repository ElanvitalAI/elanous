# 0.2.9

Smoother in the hand: a focus mode for the web terminal, a clearer terminal UI, and alerts when the Telegram bot cannot start.

## Install

```bash
curl -fsSL https://github.com/ElanvitalAI/elanous/releases/latest/download/install.sh | bash   # one line
```

or `npm install -g elanous`.

## New

- **Web terminal focus mode.** Press ⤢ or Ctrl/⌘+Shift+F to fill the screen with just the terminal.
- **Bluetooth keyboards.** When a hardware keyboard is attached, the on-screen extra-key row folds away on its own.
- **First input sooner.** A new web terminal now accepts its first input much sooner; the longest wait drops from 20 seconds to 2.
- **Terminal UI first screen** shows the web app address on one line.
- **Command palette** is ordered by what you use most, with Korean descriptions.
- **Finished turns** read "Done" or "Stopped".
- **`/remaining`** shows each account's remaining usage and when it refills, on one line. **`/provider`** lists the models you actually use.
- **Install banner no longer covers the chat box.** The «Add to Home screen» banner now sits below the chat input instead of on top of it, on phones and desktops.
- **Telegram bot alerts.** If the Telegram bot fails to start repeatedly, you get an alert that says why.

## Experimental

- In the web app, **Library › Obsidian notes** opens your vault as a folder tree you can fold.

Plus internal changes to the release loop and test gate.
