# Ticketing app starter knowledge pack

This pack has one short build card. Its scope is a runnable synthetic concert-ticketing starter, not real payment or a claim of public deployment.

The card points to the pinned template in templates/ticketing-starter and to the prior ticketing architecture decision cards. TC owns the new-app tool manifest and natural-language route. Load this pack only for a build-and-deploy request; keep architecture-only and copy-edit requests out.

Source links identify the design principle behind durable process state. The implementation and wording here are original. The starter uses Bun's SQLite implementation and contains no external package install.
