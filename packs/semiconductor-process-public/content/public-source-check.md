# 공개 출처 확인 절차

1. 공개 URL과 교과서·논문 서지를 `content/process-overview.md`의 [S1]~[S5]와 대조한다.
2. `omni-crawl`로 공개 웹 출처의 제목·접근 가능성·수집 시각을 다시 확인하고 URL 및 결과를 별도 출처 기록에 남긴다. 접근 불가 시 확인 실패로 표시한다.
3. 인용문은 재배포하지 않고 개념을 자기 문장으로 설명한다. 각 답의 주장 옆에 [S1]~[S5]와 콘텐츠 파일 경로를 붙인다.
4. 기업 문서·비공개 논문·레시피·장비 파라미터·수율·고객 자료가 발견되면 이 공개 팩에 넣지 말고 게시 심사에서 거부한다.

이 팩은 수집 실행 기록이나 영업 비밀 부재에 대한 자동 DLP 증명서가 아니다. 공개 게시 전 사람이 최종 콘텐츠와 아카이브를 심사해야 한다.
